FRADA SAVINGS v2 — goal-based savings app

1. Upload all files in this folder to the root of your existing GitHub Pages repository, replacing the previous app files.
2. Commit the changes and wait for GitHub Pages to publish.
3. Open the HTTPS app link. On iPhone use Share -> Add to Home Screen.
4. Each browser/device stores its own savings locally. There is no login or cloud sync in this simple version.

Important: changing a goal creates a fresh challenge and clears the current boxes. Export progress first if you want a backup.
